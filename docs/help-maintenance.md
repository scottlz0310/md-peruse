# 利用者向けヘルプの保守

## 配置と公開方法

- 本文・操作例・ショートカット・代替説明の正本は `src/help/content.ts`。`HELP` は日本語と英語の両方を持つ。
- 目次・モーダル・図解の構造は `src/help/HelpDialog.tsx`、配色・狭い画面の配置は `src/help/help.css`。
- 入口は `src-tauri/src/menu.rs` の `UserGuide` と、`menu-command` を受ける `src/App.tsx`。ワークスペースの有無に依存しない。
- 通常のFrontendビルドに同梱し、アプリのリリース・Store更新と同じ経路で配布する。外部ホスティング・オンラインの取得・独立した更新処理は設けない。

## 機能変更時の更新

利用者が観測できる操作・設定・制約を変えるPRでは、実装・仕様・CHANGELOGとともに日英の該当節とショートカットを更新する。`menu.rs`、`TreeView.tsx`、`TabBar.tsx`、`DocumentFind.tsx`、`App.tsx` などの実際の表記・挙動を正本に照合する。未実装機能を使えるものとして説明しない。

新しい節には日英で同じ `id` を与える。図解を変えたら、日英のキャプションも更新する。リンクがオンラインを必要とする場合は明示する。ネイティブ絶対パス・個人情報・実ユーザーの文書を図解へ入れない。

## 検証

- `bun test src/help src/App.test.tsx` で、日英の内容、目次移動とフォーカス、図解の代替説明、閉じる操作と復帰、背面へのキー伝播、メニューからの入口を確認する。
- `bun run check`、`bun run build`、Rustのformat・Clippy・テストを実行する。メニューの型はRustのテストで再生成する。
- 実ブラウザーまたは開発版で日英・配色・通常サイズ・640×480相当を目視確認する。狭い画面の目次開閉、長い見出し、図解、表の折り返し、Tab・Enter・Escを確認する。
- 同梱内容から外部ページ・画像・フォントを取得しないことを確認する。外部リンクとStoreの更新はヘルプ本体のオフライン動作とは分ける。

2026-10-09の確認では、Chromeで日英の図解・目次移動・Esc、通常サイズと640×480相当を確認した。これはFrontend表示の検証で、MSIXの更新や実UNC共有の動作検証ではない。
