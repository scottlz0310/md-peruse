# 表示サンプル

`store-demo/` は、md-peruseの機能を実際の画面で紹介するための日本語Markdownです。文書内の名称・計画・内容は架空です。サンプルもリポジトリのMITライセンスで利用できます。

| 文書 | 表示の見どころ |
| --- | --- |
| [プロジェクト概要](store-demo/01-プロジェクト概要.md) | 見出し、引用、表、タスクリスト、相対リンク |
| [構成図](store-demo/02-構成図.md) | Mermaidのフロー図と表 |
| [数式とコード](store-demo/03-数式とコード.md) | KaTeXの数式、TypeScriptのハイライト |
| [リリースノート](store-demo/04-リリースノート.md) | 箇条書き、取り消し線、タスクリスト |

`store-demo-en/` は、同じ内容の英語版です（Storeの英語（`en-us`）の掲載画像を撮影するための文書）。文書名とリンクも英語にしてあり、構成は `store-demo/` と対応します（`01-project-overview.md`、`02-architecture.md`、`03-formula-and-code.md`、`04-release-notes.md`）。日本語版を更新したときは、英語版も同じ内容に保ちます。

アプリの「フォルダーを開く」で `examples/store-demo/` を選びます。ダーク・ライトのテーマで同じ文書を表示できます。サンプル内のリンクは同じフォルダーの文書へ移動します。

掲載画像は実際のMSIXで撮影し、架空のUIを合成しません。確定前の画像・説明文はローカルで保管し、確定した素材を `docs/assets/store/` へ置く方針は [提出手順書](../docs/store-submission.md) 6章に従います。
