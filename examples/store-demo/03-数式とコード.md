# 次の一歩を、根拠から選ぶ

候補が多いときは、期待する効果と取り組みやすさを並べて考えます。
ここでは、架空の改善計画に使う簡単な優先度を定義します。

## 優先度のモデル

影響度を $I$、確信度を $C$、作業量を $E$ とすると、スコア $S$ は次の式です。

$$
S = \frac{I \times C}{E}, \qquad E > 0
$$

数値は議論の入口です。スコアだけで結論を決めず、前提も確認します。

## TypeScriptで表す

```typescript
type 改善案 = {
  名前: string;
  影響度: number;
  確信度: number;
  作業量: number;
};

function 優先度(案: 改善案): number {
  if (案.作業量 <= 0) {
    throw new Error("作業量は正の値で指定してください");
  }
  return (案.影響度 * 案.確信度) / 案.作業量;
}
```

**読み返すポイント：** 単位をそろえ、確信度の根拠を文章で残しましょう。
